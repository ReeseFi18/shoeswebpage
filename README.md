# Sole Story — A field guide to shoes

A responsive, one-page guide to six classic shoe styles.

## Publish with GitHub Pages

The site is configured to deploy automatically from the `main` branch using GitHub Actions. After pushing changes, open the repository's **Settings → Pages** and select **GitHub Actions** as the build and deployment source if it is not already selected.

Once the first deployment succeeds, visit:

https://reesefi18.github.io/shoeswebpage/

## Open the webpage

Double-click `index.html` to open the page in your browser. You can also paste this path into Chrome's address bar:

`C:\Users\2723352846\Desktop\aiClass\shoeswebpage\index.html`

The page uses photos hosted by Unsplash and fonts from Google Fonts, so an internet connection is needed to load those images and fonts. The rest of the page works locally.

## What's included

- Six shoe styles, with category filters
- Responsive layout and a mobile navigation menu
- Keyboard-friendly navigation and reduced-motion support

This project uses plain HTML, CSS, and JavaScript. No installation or build step is needed.
